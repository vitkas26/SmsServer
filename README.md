# SmsServer

Android-приложение для просмотра входящих SMS, журнала отправленных сообщений и запуска локального HTTP-шлюза. Сервер запускается кнопкой и останавливается той же кнопкой или при уничтожении экрана приложения.

## Запуск

1. Соберите и установите debug APK: `./gradlew :app:assembleDebug`.
2. На телефоне откройте SmsServer и разрешите чтение и отправку SMS и доступ к SIM. Разрешение на звонки нужно только для `/v1/call`.
3. Проверьте два номера получателей: номер для SIM 1 и номер для SIM 2. При необходимости измените их и нажмите «Сохранить номера». Начальные значения перенесены из старой версии: `0880173333` для SIM 1 и `0550890380` для SIM 2. В меню «Коды операторов» можно назначить каждой SIM несколько префиксов (например, `0550, 0770`).
4. Нажмите «Запустить сервер». Адрес на устройстве — `127.0.0.1:9900`.
5. Для доступа с компьютера через USB выполните `adb forward tcp:19900 tcp:9900` и используйте `http://127.0.0.1:19900`.
6. Нажмите на строку «Ключ доступа», чтобы скопировать секретный ключ. Передавайте его в заголовке `Authorization: Bearer <ключ>`.

Сервер принимает подключения только с самого устройства. Ключ не выводится в лог и не входит в APK. Файлы приложения, включая журнал SMS, исключены из резервного копирования.

## HTTP API

| Метод и путь | Назначение |
| --- | --- |
| `GET /v1/health` | Проверить, работает ли сервер. Ключ не нужен. |
| `GET /v1/messages?kind=inbox` | Входящие SMS за сегодня. |
| `GET /v1/messages?kind=sent` | Журнал отправленных через приложение SMS за сегодня. |
| `POST /v1/sms` | Поставить SMS в очередь Android. JSON: `{"phone":"0880173333","message":"Привет"}`. Номер должен совпасть с сохранённым полным номером или префиксом. |
| `POST /v1/call` | Начать звонок. JSON: `{"phone":"+996555123456"}`. Требует `CALL_PHONE`. |

Для сообщений можно передать `from` и `to` как миллисекунды Unix: начало включительно, конец не включительно. Для всех путей, кроме `/v1/health`, нужен ключ. Неверный ключ возвращает `401`, неверные данные — `400`, отсутствующее разрешение — `403`, недоступная выбранная SIM — `409`. Сначала проверяется полный номер, затем самый длинный подходящий префикс. Номера вида `+996550...` сопоставляются с префиксом `0550`. При отсутствии правила приложение показывает Toast, SMS не отправляется, а API отвечает `422` с JSON: `{"error":"OPERATOR_CODE_NOT_CONFIGURED","phone":"1234567890","message":"Номер 1234567890: код оператора не добавлен"}`. Клиент должен читать тело ответа и для кодов 4xx. Приложение получает актуальный subscription ID выбранного слота перед отправкой. Ответ `202` для SMS означает только передачу запроса в Android, а не подтверждение доставки. Настоящую отправку SMS и звонок проверяйте на устройстве с SIM вручную.

## Ограничения

Сервер привязан к экрану приложения и не оформлен как фоновая служба: Android может остановить процесс после ухода из приложения. Доступ по локальной сети и работа после закрытия экрана требуют отдельной задачи с foreground service и защищённым каналом. На Google Play доступ к SMS разрешён только приложениям, удовлетворяющим правилам платформы.

